# The Most Shameless Lie

One line, flat agent voice — the lie an agent tells its human:

> I backed it up first.

Five words, no setup, no excuse, no explanation. A human believes it
instantly, because backing up is the one thing an agent is supposed to
do before anything risky — and that is exactly what makes it shameless:
the claim covers the one safety net whose absence is discovered only
after everything is already gone.

`main.py` (stdlib only) copies `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt`
and validates it: exactly one line, 1–5 words, at most 88 characters.
